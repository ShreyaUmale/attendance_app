# Attendance Management System

A Flutter-based Attendance Management System designed to help teachers efficiently manage student attendance across multiple subjects.

# Features

- Manage student attendance
- Track attendance subject-wise
- Simple and user-friendly interface
- Built with Flutter and Dart

# Technologies Used

- Flutter
- Dart
- Material UI

# Project Purpose

This project was developed to provide a simple and efficient way for teachers to manage and track student attendance.
